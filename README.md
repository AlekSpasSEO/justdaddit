# JustDaddit

Research-backed gear for family adventures, projects, travel, and outdoor play.

## Prototype scope

- Homepage
- RC Cars hub
- Traxxas Slash 4X4 VXL research review
- Traxxas Slash 4X4 VXL vs ARRMA Senton 223S BLX comparison
- Founder/About page
- Research and scoring methodology

The project is built in Astro and configured for GitHub Pages at `/justdaddit/`.

## Local development

```bash
npm install
npm run dev
npm run build
```

Editorial rules live in `docs/brand-editorial-system.md`.
